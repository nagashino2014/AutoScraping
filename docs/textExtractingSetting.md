## 1. 개요

### 1.1 목적

웹 스크래퍼에서 수집한 다양한 형식의 파일(PDF, HWP, DOCX, XLSX 등)에서 텍스트를 추출하고,
청킹/임베딩을 거쳐 벡터 데이터베이스에 저장하는 전체 파이프라인을 관리하는 화면이다.

### 1.2 메뉴 구조

```
추출 및 벡터화 (/processing)
├── 텍스트 추출 (/processing/extract)      ← 본 문서 주요 대상
├── 청킹 및 임베딩 (/processing/chunking)  ← chunkingEmbeddingSetting.md 참조
└── 벡터화 (/processing/vectorize)         ← chunkingEmbeddingSetting.md 참조
```

### 1.3 핵심 요구사항 (WebScraperRAG.md 3.2절 기반)

- **스케줄 기반 저장**: 수집된 문서는 기관/보드별로 분류되어 저장
- **파싱 현황 시각화**: 도넛 차트로 스크래핑 진행률/파싱 완료율 표시
- **텍스트 추출 결과 지표**:
  - 파일 전체 및 형식별(PDF, HWP 등) 추출 성공률/실패율
  - 파싱 작업 수행 일시 및 총 소요 시간
  - 추출된 텍스트 데이터의 총 규모(Token/MB)

### 1.4 데이터 저장 경로

```
C:\CodingProject\Web Scraper Final\frontend\save\ScrapingData\
├── {기관ID}\
│   ├── {보드ID}\
│   │   ├── 2026-01\
│   │   │   ├── document1.pdf
│   │   │   ├── document2.hwp
│   │   │   └── ...
│   │   └── 2026-02\
│   └── ...
└── ...
```

export type ExtractedFile = {

  quality_score?: number; // 품질 점수 (0.0 ~ 1.0)

    vocab_coverage: number;
    broken_char_ratio: number;

### 10.3 검증 모듈 구현

```python
from konlpy.tag import Mecab
import re
from typing import Dict

class TextQualityValidator:
    """로컬 텍스트 품질 검증 시스템 (98-99% 정확도 목표)"""

    def __init__(self):
        self.morpheme_analyzer = Mecab()
        self.korean_vocab = self._load_korean_vocab()
        self.domain_vocab = self._load_domain_vocab()

        self.weights = {
            "korean_ratio": 0.15,
            "morpheme_validity": 0.25,
            "vocab_coverage": 0.20,
            "broken_char_ratio": 0.15,
            "sentence_structure": 0.10,
            "ngram_anomaly": 0.10,
            "repetition_anomaly": 0.05
        }

    def validate(self, text: str) -> Dict:
        """전체 검증 수행"""
        if not text or len(text.strip()) < 10:
            return {"score": 0.0, "details": {}, "recommendation": "llm_extract"}

        scores = {
            "korean_ratio": self._check_korean_ratio(text),
            "morpheme_validity": self._check_morpheme_validity(text),
            "vocab_coverage": self._check_vocab_coverage(text),
            "broken_char_ratio": self._check_broken_chars(text),
            "sentence_structure": self._check_sentence_structure(text),
            "ngram_anomaly": self._check_ngram_anomaly(text),
            "repetition_anomaly": self._check_repetition_anomaly(text)
        }

        total_score = sum(scores[k] * self.weights[k] for k in scores)
        recommendation = self._get_recommendation(total_score)

        return {
            "score": round(total_score, 4),
            "details": scores,
            "recommendation": recommendation,
            "threshold": 0.85
        }

    def _get_recommendation(self, score: float) -> str:
        if score >= 0.85:
            return "pass"
        elif score >= 0.70:
            return "review"
        elif score >= 0.50:
            return "llm_verify"
        return "llm_extract"
```

### 11.3 하이브리드 OCR 구현

```python
from paddleocr import PaddleOCR
import easyocr
import pytesseract
import numpy as np
from difflib import SequenceMatcher

class HybridOCREngine:
    """다중 OCR 엔진 앙상블 (97-99% 정확도)"""

    def __init__(self, use_gpu: bool = False):
        self.paddle = PaddleOCR(lang='korean', use_angle_cls=True,
                                use_gpu=use_gpu, ocr_version='PP-OCRv4')
        self.easy = easyocr.Reader(['ko', 'en'], gpu=use_gpu)
        self.weights = {'paddle': 0.50, 'easyocr': 0.35, 'tesseract': 0.15}

    def extract(self, image) -> dict:
        """앙상블 OCR 실행"""
        results = {
            'paddle': self._run_paddle(image),
            'easyocr': self._run_easyocr(image),
            'tesseract': self._run_tesseract(image)
        }

        # PaddleOCR 신뢰도 95% 이상이면 단독 사용
        if results['paddle']['avg_confidence'] >= 0.95:
            return {'text': results['paddle']['text'], 'method': 'paddleocr_solo'}

        # 앙상블 병합
        merged = self._ensemble_merge(results)

        return {'text': merged, 'method': 'hybrid_ensemble', 'details': results}
```

### 12.3 제목글 표 오검출 문제 해결

> **해결된 이슈**: 문서 상단 제목글 박스가 표로 잘못 검출되는 현상

#### 12.3.1 문제 상황

정부 문서에서 흔히 사용되는 제목글 박스 형식:

```
┌─────────────────────────────────────────────────────┐
│ 보도자료                                            │
│ 1월 16일, 충청권·전북 지역 고농도 초미세먼지 ...     │
└─────────────────────────────────────────────────────┘
```

이러한 영역이 표로 오인되어 잘못된 표 데이터가 생성됨.

#### 12.3.2 해결 방안

**1단계: line_detector.py - is_valid_table() 강화**

```python
def is_valid_table(self) -> bool:
    """표 유효성 검증 (강화됨)"""

    # 최소 선 수 검사
    if len(self.horizontal) < 2 or len(self.vertical) < 2:
        return False

    # ★ 핵심 필터: 수직선 2개만 있으면 무조건 제외 (단일 컬럼 = 텍스트 박스)
    if len(self.vertical) == 2:
        return False

    # 가로/세로 비율 검사 (너무 넓고 낮은 영역 제외)
    width = max(l.x1 for l in self.horizontal) - min(l.x0 for l in self.horizontal)
    height = max(l.y1 for l in self.vertical) - min(l.y0 for l in self.vertical)

    # 1행 2열 구조: 비율 4 초과시 제외
    if len(self.horizontal) == 2 and len(self.vertical) == 3:
        if height > 0 and width / height > 4:
            return False

    # 소규모 그리드: 비율 5 초과시 제외
    if len(self.horizontal) <= 4 and len(self.vertical) <= 4:
        if height > 0 and width / height > 5:
            return False

    return True
```

**2단계: table_builder.py - \_clean_title_rows() 추가**

```python
def _clean_title_rows(self) -> None:
    """표 상단 제목글 행 자동 제거"""
    if self._title_cleaned or self.rows < 4:
        return

    self._title_cleaned = True

    # 데이터 행 평균 셀 수 계산 (하단 절반 기준)
    lower_half = self.rows // 2
    row_cell_counts = [0] * self.rows
    for cell in self.cells:
        row_cell_counts[cell.row] += 1

    data_row_avg_cells = sum(row_cell_counts[lower_half:]) / max(1, len(row_cell_counts[lower_half:]))

    # 제목글 행 감지 및 제거
    rows_to_remove = []
    for row_idx in range(self.rows):
        num_cells = row_cell_counts[row_idx]

        # 조건 1: 단일 셀이 전체 열을 span
        is_single_cell_row = (num_cells == 1)

        # 조건 2: 데이터 행 평균의 30% 미만
        is_significantly_fewer = (num_cells < data_row_avg_cells * 0.3)

        # 조건 3: 데이터 패턴 부재
        row_text = ' '.join(c.text for c in self.cells if c.row == row_idx)
        has_data_pattern = bool(re.search(r'㎍/㎥|①|②|③|%|원|시간|\d{2,4}[-./]\d{1,2}', row_text))

        if is_single_cell_row or (is_significantly_fewer and not has_data_pattern):
            rows_to_remove.append(row_idx)
        else:
            break  # 첫 데이터 행을 만나면 중단

    # 행 제거 및 인덱스 조정
    if rows_to_remove:
        self.cells = [c for c in self.cells if c.row not in rows_to_remove]
        for cell in self.cells:
            cell.row -= len([r for r in rows_to_remove if r < cell.row])
        self.rows -= len(rows_to_remove)
```
